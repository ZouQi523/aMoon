# aMoon · 2026重返月球

浏览器中的月球探索体验，包含月面行走、月球车、科学实验、登月舱与轨道交会对接场景。

## 本地运行

在工程目录启动静态文件服务：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8000/>。入口为 `index.html`，其中内嵌了游戏脚本及主要素材。

## 构建网页发布目录

```sh
python3 scripts/build_web.py
```

构建结果位于 `web-release/play/`，脚本将页面内嵌的样式、脚本及部分素材拆分为同源静态文件。该目录由源码生成，不纳入版本控制。

## 工程内容

- `index.html`：游戏入口和源码。
- `scripts/build_web.py`：静态网页构建脚本。
- `promotion/v01` 至 `promotion/v04`：宣传片脚本、对白时间线、字幕及部分参考图片。

宣传片录屏、成片与生成音频保留在本地，不纳入 Git。宣传制作脚本另需 Playwright、FFmpeg 等工具；配音脚本使用本地 Kokoro 模型，具体依赖见各脚本。

## 素材来源

游戏中的第三方模型、影像和录音署名见游戏内飞行手册。宣传片素材说明见 [分镜与素材来源](promotion/v01/分镜与素材来源.txt)。第三方素材适用各自的授权条件。
